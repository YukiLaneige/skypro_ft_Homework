Git

  • Основные инструменты описанные в разделе "Терминал MacOS" так же работают и в Git.
  • git init – инициализировать репозиторий в папке.
  • git status – проверить состояние файлов.
  • git add . – добавить все изменения в индекс для сохранения.
  • git commit -m "сообщение" – сохранить изменения с комментарием.
